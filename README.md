# 📱 Mobile Sales Dashboard | Power BI

## 📌 Project Overview

The **Mobile Sales Dashboard** is an interactive Business Intelligence solution developed using **Microsoft Power BI**. This project transforms raw mobile sales data into meaningful visual insights, enabling users to monitor business performance and make informed decisions.

The dashboard provides a comprehensive overview of sales performance through dynamic visualizations, KPIs, and interactive filters.

---

## 🎯 Objectives

* Analyze overall mobile sales performance.
* Track sales trends over time.
* Compare the performance of different mobile brands and models.
* Identify top-performing cities.
* Understand customer ratings and purchasing behavior.
* Analyze payment methods used by customers.
* Build an interactive dashboard for efficient business analysis.

---

## 📊 Dashboard Features

* Total Sales KPI
* Total Quantity Sold
* Total Transactions
* Average Sales Value
* Monthly Sales Trend Analysis
* Brand-wise Sales Performance
* Mobile Model Comparison
* City-wise Sales Distribution
* Customer Rating Analysis
* Payment Method Distribution
* Interactive Slicers and Filters
* Clean and User-Friendly Dashboard Design
